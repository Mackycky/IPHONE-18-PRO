# iPhone 18 Pro | Glacier Edition ❄️

Una landing page conceptual inspirada en el diseño y la experiencia visual de Apple, dedicada al imaginario iPhone 18 Pro Glacier Edition.

## 📱 Sobre el proyecto

Este proyecto consiste en el desarrollo de una landing page de producto, con una estética minimalista, moderna y premium.

La propuesta busca transmitir la identidad Glacier a través de tonos azul hielo, plateados y blancos, acompañados de imágenes y elementos visuales cuidadosamente seleccionados.

**Nota:** Este es un proyecto conceptual, no oficial y sin afiliación con Apple.

## ✨ Características

- Diseño visual minimalista y premium.
- Presentación del producto.
- Secciones dedicadas al diseño, cámara y rendimiento.
- Galería de imágenes interactiva.
- Experiencia de compra conceptual mediante una ventana modal.
- Sección de descubrimiento y llamada a la acción.
- Diseño adaptable a diferentes dispositivos.
- Favicon personalizado con identidad Glacier.

## 🎨 Identidad visual

La estética está inspirada en una experiencia tecnológica elegante y sofisticada.

**Paleta de colores:**
- Azul hielo.

- Blanco.
- Gris frío.
